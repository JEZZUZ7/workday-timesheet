# Workday timesheet

อ่านคอลัมน์ของผู้ใช้ในไฟล์ตารางงานของทีม แปลงเป็น entry (Regular / OT) แล้วกรอกลง Workday Enter Time
ผ่าน Edge ที่ผู้ใช้ login เอง ทุกอย่างทำผ่าน `scripts/timesheet.py` เท่านั้น

## กฎที่ห้ามฝ่าฝืน
- **ห้ามกด Submit** ใน Workday และห้ามทำอะไรที่ทำให้เกิดการ Submit ผู้ใช้ตรวจแล้วกด Submit เอง
- **ห้ามควบคุม browser เอง** (เขียน Playwright/Selenium เฉพาะหน้า, ใช้ browser tool หรือ MCP ใดๆ กับ Workday)
  ถ้าสคริปต์ error ให้รายงานผลและภาพหน้าจอ แล้วให้ผู้ใช้แก้ในหน้าเว็บเอง
- **ห้ามรัน `fill`** จนกว่าผู้ใช้จะตอบยืนยันกรอกจริงของเดือน/ช่วงนั้นในบทสนทนานี้ หลังเห็นผล preview และ dryrun แล้ว
  การยืนยันครั้งก่อนหรือของเดือนอื่นใช้ไม่ได้
- ห้ามถาม เก็บ หรือพิมพ์ username/password และห้ามพยายามผ่าน SSO/MFA ให้ผู้ใช้ login เองในหน้าต่าง Edge
- ห้ามอ่าน copy หรือส่งต่อโฟลเดอร์ `wd-profile` (session ที่ login ไว้)
- ห้ามแก้ไฟล์ Excel ต้นฉบับ ข้อมูลผิดให้ผู้ใช้แก้ในไฟล์บน Teams แล้วรัน preview ใหม่
- ห้ามแก้ไฟล์ใน `scripts/` ของ plugin ระหว่างใช้งาน

## วิธีรัน
สคริปต์อยู่ที่ `scripts/timesheet.py` ใต้ base directory ของ skill นี้ (path ที่แสดงตอนโหลด skill)
รันด้วย Python 3.10+ ของเครื่อง (Windows: `python` หรือ `py -3`) ใส่ path ในเครื่องหมายคำพูดเสมอ:

```
python "<base>/scripts/timesheet.py" <คำสั่ง> [ตัวเลือก]
```

ครั้งแรกจะสร้าง venv และติดตั้งแพ็กเกจเองใน data dir (`%LOCALAPPDATA%\workday-timesheet`) ใช้เวลาสักครู่
`dryrun` และ `fill` อาจรอผู้ใช้ login นานถึง 15 นาทีและกรอกหลายสิบ entry ให้รันแบบ background
(`run_in_background`) แล้วรอแจ้งเตือนเมื่อจบ อย่ารันแบบรอผลตรงๆ

| คำสั่ง | ทำอะไร |
|---|---|
| `setup --show` | แสดงค่าที่ตั้งไว้ |
| `setup [--team-config P] [--excel P] [--person N]` | ตั้งค่าผู้ใช้ |
| `preview YYYY-MM` หรือ `preview --week YYYY-MM-DD` | อ่าน Excel สร้าง preview และคำเตือน ไม่แตะ Workday |
| `dryrun YYYY-MM [opts]` | เปิดฟอร์มใน Workday ทีละ entry แล้วกด Cancel ไม่บันทึก |
| `fill YYYY-MM --confirmed [opts]` | กรอกจริง (กด OK ทีละ entry) ไม่กด Submit |

ตัวเลือกของ dryrun/fill: `--only-date YYYY-MM-DD` (ซ้ำได้), `--skip-date YYYY-MM-DD` (ซ้ำได้),
`--accept-under-8h`, `--person N`, `--port N` ใช้ `--week YYYY-MM-DD` แทนเดือนได้ ถ้า preview ทำแบบสัปดาห์

## ขั้นตอน

### 1. ตรวจการตั้งค่า
รัน `setup --show` ถ้ายังไม่มี `team_config` หรือ `person_column` ให้รัน `setup` แล้วดู exit code:
- `3` ไม่พบ team config (`timesheet.team.yaml`): ถามผู้ใช้ว่าไฟล์อยู่ที่ไหน (ปกติคนดูแลทีมวางไว้ในโฟลเดอร์
  เดียวกับไฟล์ตารางงานบน Teams) แล้วรันใหม่พร้อม `--team-config "<path>"`
- `5` ไม่พบไฟล์ Excel: ให้ผู้ใช้กด *Add shortcut to My files* ที่**โฟลเดอร์**ที่มีไฟล์ใน Teams/SharePoint
  (ไม่ใช่ที่ตัวไฟล์ ซึ่งได้แค่ไฟล์ `.url`) แล้วรอ OneDrive sync หรือขอ path แล้วใช้ `--excel "<path>"`
- `4` ต้องเลือกชื่อ: แสดงรายชื่อพร้อมเลขที่สคริปต์พิมพ์ ให้ผู้ใช้เลือก (เลขหรือชื่อ) แล้วรันใหม่พร้อม `--person "<ชื่อ>"`
  ห้ามเดาชื่อเอง

### 2. Preview
รัน `preview YYYY-MM` (ผู้ใช้ไม่บอกเดือน = ถามก่อน) สคริปต์แสดงบรรทัด "อ่าน <ไฟล์> (แก้ไขล่าสุด ...)"
ถ้าผู้ใช้เพิ่งแก้ Excel แต่เวลาเก่ากว่านั้น ให้บอกว่า OneDrive อาจยัง sync ไม่เสร็จ

สรุปให้ผู้ใช้: ชั่วโมง Regular/OT รวม, วันที่มีปัญหา และคำเตือนแต่ละรายการเป็นภาษาคน
ไฟล์ preview อยู่ที่ `<data dir>\output\<ชื่อ>\preview_<เดือน>.xlsx` ผู้ใช้เปิดแก้ก่อน dryrun/fill ได้

| คำเตือน | ความหมาย / สิ่งที่ต้องถาม |
|---|---|
| `UNDER_8H` | วันทำงานที่ชั่วโมงปกติไม่ครบ ถามว่าจะแก้ Excel หรือกรอกตามนั้น (ต้องใช้ `--accept-under-8h`) |
| `PADDED_8H` | Regular 6-7 ชม. ถูกเติมให้ครบ 8 แจ้งให้ทราบ |
| `LEAVE_DAY` | วันลา ไม่กรอกอัตโนมัติ ถ้ามีงานในวันลา ผู้ใช้ต้องตัดสินใจและกรอกเองในหน้าเว็บ |
| `TIME_IN_JOB_TEXT` | มีเวลาในบรรทัด Job ที่ไม่อยู่ในบรรทัด Time อาจเป็น OT ที่ลืมใส่ |
| `FREE_TEXT` | ข้อความนอกบล็อกงาน เช่นสอบ/กิจกรรม ที่ไม่ได้กลายเป็น entry |
| `NO_TIME` / `UNKNOWN_CONTRACT` | บล็อกไม่มีเวลา / เลขสัญญาไม่อยู่ในชีต Contract |
| `CONTRACT_FORMAT` | เลขสัญญาไม่ใช่รูปแบบปกติ (เช่น `A99-P001`) มักหา Time Type ใน Workday ไม่เจอ ถามว่าจะแก้ Excel หรือกรอกเอง |
| `UNKNOWN_ROLE` | Role ว่างหรือไม่อยู่ในการจับคู่ของ team config entry นี้จะ error ให้แก้ Role ใน Excel หรือแจ้งคนดูแลทีม |
| `CROSS_MIDNIGHT` / `OVERLAP` | งานข้ามเที่ยงคืนถูกแยกเป็น 2 วัน / ช่วงเวลาทับกัน |

ถ้าต้องแก้ข้อมูล ให้ผู้ใช้แก้ Excel บน Teams แล้วรัน preview ใหม่

### 3. Dry-run
บอกผู้ใช้ก่อนรัน: จะมีหน้าต่าง Edge เปิดขึ้น ถ้ายังไม่ได้ login ให้ login Workday เอง
(Workday ต้องเป็นภาษา English) และ**ห้ามคลิกในหน้าต่าง Edge ระหว่างสคริปต์ทำงาน**
รัน `dryrun YYYY-MM` แบบ background แล้วสรุปผล: `DRY` = กรอกได้, `SKIP` = มีอยู่แล้ว/วันลา, `ERROR` = มีปัญหา
entry ที่ error มีภาพ `fill_error_*.png` ใน output ให้เปิดดูเพื่ออธิบายสาเหตุ
สคริปต์เช็คกับ Workday จริงทุกครั้ง entry ที่ผู้ใช้ลบเองจะถูกกรอกใหม่ พร้อมข้อความ "เคยกรอกแล้วแต่ไม่พบใน Workday"
ท้ายผลมี 2 หัวข้อที่ต้องแจ้งผู้ใช้ทุกครั้ง: "ไม่ได้กรอก" (entry ที่ error เช่นหา Contract ใน Workday ไม่เจอ)
และ "ใน Workday มี entry ที่ไม่ตรงกับ preview" (อาจกรอกเองหรือชั่วโมงไม่ตรง เสี่ยงซ้ำ)

### 4. ยืนยันแล้วกรอกจริง
ถามผู้ใช้ตรงๆ ว่าจะกรอกจริงของเดือน/ช่วงนั้นหรือไม่ พร้อมจำนวน entry และวันที่จะข้าม
รอคำตอบยืนยันชัดเจน แล้วจึงรัน `fill YYYY-MM --confirmed` แบบ background (ใส่ `--accept-under-8h`
เฉพาะเมื่อผู้ใช้ตกลงเรื่อง UNDER_8H แล้ว) รันซ้ำได้ สคริปต์ข้าม entry ที่กรอกแล้ว

### 5. ปิดงาน
สรุปผลจากบรรทัด "สรุป:" ของสคริปต์ รายการวันลาที่ไม่ได้กรอก และ error ที่เหลือ
ย้ำทุกครั้งว่า **ยังไม่ได้กด Submit** ผู้ใช้ต้องตรวจชั่วโมงและ Alerts ในหน้าต่าง Edge แล้วกด Submit เอง

## แก้ปัญหา
| อาการ | สิ่งที่ทำ |
|---|---|
| `ต่อ Edge ที่พอร์ต 9222 ไม่ได้` | ให้ผู้ใช้ปิดหน้าต่าง Edge ที่สคริปต์เปิดไว้แล้วรันใหม่ หรือใช้ `--port 9223` |
| `หมดเวลารอ login` | ถามว่า login แล้วหรือยัง, Workday เป็นภาษา English หรือไม่ |
| `dialog เปิดผิดวัน` | สคริปต์อ่านวันที่ได้ทั้งแบบ d/m, m/d, ISO และแบบมีชื่อเดือน ถ้ายังขึ้นอยู่ ให้ดูข้อความบนหัว dialog ในข้อความ error ถ้าเป็นวันเดียวกันแต่รูปแบบแปลก ให้ผู้ใช้เพิ่ม `workday: {date_format: "<รูปแบบ strftime>"}` ในไฟล์ config ของผู้ใช้ |
| `ไม่มี task/Time Entry Code สำหรับ role` | Role นี้ยังไม่อยู่ใน team config แจ้งคนดูแลทีมให้เพิ่ม |
| แก้ข้อมูลวันที่กรอกไปแล้ว | สคริปต์ไม่ลบ entry เดิม ผู้ใช้ต้องลบใน Workday เองก่อนรัน fill ใหม่ |
